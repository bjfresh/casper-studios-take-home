# components/

| Directory   | Holds                                                    |
| ----------- | -------------------------------------------------------- |
| `ui/`       | Domain-free design-system primitives                     |
| `features/` | Domain UI, one directory per feature                     |
| `layout/`   | Header, footer, shell chrome                             |
| `icons/`    | Icon registry (`generated/` is machine-written)          |
| `modals/`   | Dialogs composed from `ui/` primitives                   |

Component files are PascalCase (`ItemList.tsx`).
